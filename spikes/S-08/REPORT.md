# S-08 REPORT (IME 候補窓の位置)

状態: **判定済み (MS-IME のみ)** (2026-10-21)。Google 日本語入力は試験機に未導入のため未確認。

## 方法

`spikes/auto/measure-s08.ps1` で自動測定した。`spike-s08 --marker` がカーソルのセルをマゼンタで塗り、画面から位置 (px) を読む。IME を開いてひらがなにし、`nihongo` + Space (変換) + Space (候補の一覧) を `SendInput` で送り、候補一覧の出る前後のスクリーンショットの差分から候補窓の矩形を求め、候補窓の縁とカーソルのセルの縦の距離を行数で出した (合格は 1 行以内)。

## 環境

| 項目 | 値 |
|---|---|
| OS | Windows 11 |
| IME | MS-IME (日本語、新しい候補窓) |
| 端末 | Windows Terminal (WT_SESSION あり)、conhost |

## 結果 (カーソルのセルの縁から候補窓の縁までの縦の距離。単位は行)

| 場面 | Windows Terminal | conhost |
|---|---|---|
| 編集面・全角の行 | ○ 0.03 (下) | ○ 0.29 (下) |
| 編集面・半角の行 | ○ 0.03 (下) | ○ 0.33 (下) |
| 編集面・画面の下寄り | ○ 0.03 (下) | ○ 0.29〜0.33 (下) |
| 編集面・右寄り | ○ 0.03 (下) | ○ 0.29 (下) |
| オーバーレイの入力欄 (画面の下端) | ○ 0.06 (**上へ反転**) | ○ 0.33 (下) |
| 同期出力 (CSI ? 2026) on | ○ 0.03 | ○ 0.33 |
| 非入力契機の再描画 (200 ms ごと) | ○ 0.03 | ○ 0.29 |
| カーソルを隠さない | ○ 0.03 | ○ 0.33 |

- 変換の途中の文字列 (インライン) はカーソルの位置に出る。候補窓は横方向にカーソルより約 28〜44 px 左から始まる (候補番号の列の分)。
- 候補窓は最上位のトップレベルウィンドウとして列挙されない (IME のプロセスが描く)。位置はスクリーンショットの差分で測った。
- Windows Terminal の IME は新しいウィンドウでは開始時の状態が一定しない (ON のことも OFF のこともある)。測定は毎回 `IMC_SETOPENSTATUS` で開いてから行った。

## 結論

- FR-605 AC-1 (候補窓がカーソルから 1 行以内) は、**MS-IME では Windows Terminal・conhost の両方で合格**。ハードウェアカーソルの配置と、毎フレームのカーソルの隠し/出し直し、同期出力のどれでも位置は変わらない。
- **Google 日本語入力は未確認**。導入した環境で `spikes/auto/measure-s08.ps1` を再実行すれば測れる (候補窓が最上位ウィンドウでなくても差分で測るため、IME に依らない)。
- 不合格の場面は無いので、端末別の既知制約は追加しない。
