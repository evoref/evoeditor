Usage: evoeditor [OPTIONS] [--] [FILE | -]...
  使い方: evoeditor [オプション] [--] [ファイル | -]...

A modeless text editor for the terminal.
  端末で動く、モードのないテキストエディタです。

Options:
  オプション:
  -R, --readonly                       Open the file read-only
                                       読み取り専用で開きます
  -e, --encoding <label>               Open the file with the given encoding
                                       文字コードを指定して開きます
  --locale <lang>                      Set the UI language: ja, en, or a language with a file in locales/ (overrides ui.locale and EVE_LANG)
                                       画面の言語を指定します: ja / en、または locales/ に言語ファイルを置いた言語 (設定 ui.locale と EVE_LANG より優先)
  -c, --config <file>                  Read this settings file instead of config.toml (repeatable; later files win)
                                       config.toml の代わりにこの設定ファイルを読みます (複数指定可。後のものが優先)
  -N, --no-config                      Do not read config.toml, keymap.toml, theme files, or language files (use the defaults)
                                       config.toml・keymap.toml・テーマファイル・言語ファイルを読みません (既定値で動きます)
  -s, --set <key>=<value>              Override one setting (e.g. --set view.wrap=soft)
                                       設定を 1 項目上書きします (例: --set view.wrap=soft)
  --log-level <level>                  Set the log level: error, warn, info, debug, or trace (overrides EVE_LOG)
                                       ログの水準を指定します: error / warn / info / debug / trace (EVE_LOG より優先)
  --crash-report                       Show the latest crash log and exit
                                       最新のクラッシュログを表示して終了します
  --check-config                       Check the settings, print the problems, and exit
                                       設定を確かめて問題を表示し、終了します
  --dump-config [--defaults] [--json]  Print the resolved settings (or the defaults) and exit
                                       解決した設定 (または既定値) を表示して終了します
  -V, --version                        Show the version and build information
                                       版とビルド情報を表示して終了します
  -h, --help                           Show this help
                                       このヘルプを表示して終了します
  --wait                               Accepted for $EDITOR compatibility; has no effect
                                       $EDITOR に設定するときの互換用です (何もしません)
  -                                    Read standard input into an untitled document
                                       標準入力を読んで無題の文書として開きます
  --                                   Treat the rest as file names
                                       以降をファイル名として扱います

Encodings: utf-8, utf-8-bom, utf-16le, utf-16be, shift_jis, euc-jp, iso-2022-jp
  使える文字コード名: utf-8, utf-8-bom, utf-16le, utf-16be, shift_jis, euc-jp, iso-2022-jp
Exit codes: 0 normal, 1 runtime error, 2 usage error, 3 errors in the settings (--check-config), 5 no terminal, 70 internal error
  終了コード: 0 正常、1 実行時エラー、2 使い方の誤り、3 設定にエラー (--check-config)、5 端末なし、70 内部エラー
