## 所見 (2026-11-08、手で追記)

- **計測の条件**: 判定コミット `d46f528` (v0.3.0 の版上げの後の `develop` の先頭)。リポジトリは外付けの SSD にあるので、exe (`CARGO_TARGET_DIR`) は内蔵 SSD の NTFS の上に置いた (09 §5.3 (e))。AC 電源で、電源モードは「最適なパフォーマンス」。計測中はブラウザなどの重いアプリを閉じた。
- **BM-104 (表では v0.2.0 より 30〜45% 遅いが、劣化ではない)**: 表の p50 は 10m 18.50 ms・100m 180.20 ms・100m-sjis 416.30 ms で、v0.2.0 の記録 (12.70 / 139.40 / 285.40 ms) より遅い。判定の後に `cargo bench -p eve-platform --bench bm_104_202` を、v0.2.0 の判定コミット (`6728fde`) と判定コミット (`d46f528`) で同じ機械・同じ時に交互に 2 回ずつ測ると、p50 は次のとおりで差が無い。表の値は、計測中の機械の一時的な状態 (同じコミットで測り直すと 10m で 11.6〜16.2 ms、100m-sjis で 285〜375 ms と揺れた) によるものと見る。

  | コミット | 10m | 100m | 100m-sjis |
  |---|---|---|---|
  | `6728fde` (v0.2.0) 1 回目 / 2 回目 | 12.0 / 12.0 | 135.3 / 138.0 | 290.8 / 292.9 |
  | `d46f528` (v0.3.0) 1 回目 / 2 回目 | 12.0 / 12.2 | 135.5 / 139.2 | 287.1 / 290.5 |

- **BM-106 (表では v0.2.0 より遅いが、劣化ではない)**: 表の BM-106 は BM-104 の直後に測っていて、同じ時間帯に当たった (例: ascii insert_mid の p50 は 15.50 → 24.26 ms)。`cargo bench -p eve-testkit --bench bm_106` を同じく交互に 2 回ずつ測ると、p50 (ms) は差が無い (目標は p99 100 ms で、表の値でも合格)。

  | `d46f528` 1 回目 / 2 回目 | 29.65 / 29.47 | 16.50 / 16.17 | 26.36 / 25.93 | 11.15 / 11.13 | 25.70 / 25.84 | 12.03 / 11.94 |

- **改善した行 (v0.3 の効率化、08 §2.4 の追加ゲート (b))**: BM-103a の p50 0.277 → 0.110 ms、BM-103b の p50 1.57 → 0.93 ms・p99 4.90 → 3.00 ms、BM-103b-search の p50 2.44 → 1.16 ms (v0.2.0 の例外 (不合格) は解消。#334)、BM-102a 7.81 → 4.97 ms、BM-102b 49.10 → 26.72 ms、BM-101b 29.88 → 24.42 ms、BM-107 1.37 → 0.92 ms、BM-103b-reconcile / swap60 / clip60 / clip100 もそれぞれ約 3 割短い。
- **前の版との比較 (その他)**: BM-205 (exe の大きさ) は 4,962,304 → 5,115,904 バイト (+3.1%。v0.3 で足したコマンド・文言・生成リファレンスの隠しオプションなど)。BM-201 (アイドル時のメモリ) は 4.64 → 4.43 MB。
- **BM-B01 / PRF-20 (参考、ratatui の依存)**: クリーンな `cargo build --release -p evoeditor --timings` (内蔵 SSD、判定コミット) は実時間 63 秒、コンパイルの単位 87 個・CPU 時間の合計 179.5 秒。ratatui とその推移的依存と見られる単位 (crate の名前で拾った概算) は 17 個・CPU 時間 19.4 秒 (約 11%。重い順に itertools 3.5 s・ratatui-widgets 2.8 s・ratatui-core 2.7 s・darling_core 1.8 s)。`cargo tree` で ratatui の推移的依存 (normal) は 50 個 (eve-tui の全体は 90 個)。exe の中の ratatui の占める大きさ (`cargo bloat`) は未計測。外すかの判断は v0.6 の前 (findings の PRF-20)。
