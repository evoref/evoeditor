## 測った条件

- bm_109 を 2 回続けて (各約 20 秒)、その後に bm_pty を 3 巡 (12 回、約 30 分)。各回の前に、全体の CPU の使用率を 1 秒ごとに 5 回見て、平均 16 % 未満かつ cargo / rustc のプロセスが無いときに始めた (上限 10 分待つ)。始める前の平均は bm_109 14.5 / 15.1 %、bm_pty の 1・2 巡 10.0〜13.4 %、3 巡 4.1〜8.8 %。この機械の常駐のプロセスで、何もしなくても 10〜15 % ほどある。
- **例外**: bm_pty の 3 巡目の BM-103b-search-1m-regex (`103r #3`) は、別の作業ツリーの cargo のビルド (cargo / rustc 5 プロセス) が 10 分以上続いたため、待ちの上限に届き、その中で測った (CPU の平均 8.8 %)。値 (p50 0.97 / p99 1.73 ms) は 1・2 巡目と同じ程度だった。
- 電源に接続。Defender のリアルタイム保護は無効 (環境の登録どおり)。
- 測る exe (`CARGO_TARGET_DIR`) と計測データ (`TEMP` の下に `bm_pty` が作る 1 MB / 100 MB のファイル。`bm_109` はメモリ上の `MemFs`) は内蔵 NVMe SSD (NTFS) の上 (09 §5.3 (b) / (e))。リポジトリは USB 接続の外付けのドライブの上だが、計測の区間には入らない。
- 端末は `bm_pty` の ConPTY (120 × 40)。Rust stable (1.99 系)、`bench` プロファイル (release + debuginfo)。

## 所見

- **Must の 2 つ (BM-103b-search-multiline-1m / BM-103b-search-multiline) は NFR-103 を満たす**。BM-109-compat も NFR-109 の目標 300 ms に対して約 16 ms。BM-109m は S-04 の基準 (全文連結の 2 倍以内) を満たす (0.29〜0.93 倍)。
- **要検討 (NFR-103 の余裕を食う経路)**: 重くない検索語でも、繰り返しの上限が判定の値 (1000) に近く、行をまたぐもの (`[^\n]{0,1000}\nzq`) は、行の長い文書 (行 8〜32 KiB) の 64 KiB 以下の窓の同期検索 (メインスレッドの可視範囲の強調) に p99 6〜10 ms・最大 8〜13 ms かかった。上限が 1 桁小さい `{0,100}` は p99 0.15〜0.22 ms で、約 50 倍違う。長い行では、各位置から始まる有界の繰り返しで遅延 DFA の状態が増え、処理の速さが約 10 MB/s に落ちるためと見ている (推測。100 MB の短い行の文書では同じ形の走査は速い)。この同期検索は打鍵の区間 (BM-103b-search-multiline-1m) には入らず、照合器が届いた後の Frame と、スクロール (可視行が変わる打鍵) の Frame に入る。**BM-103b の判定 (上の表) は満たすが、この形の検索語を長い行の文書で使ってスクロールすると、打鍵の p99 が 8 ms を超えうる**。03 §12.3.1 の値 (`SEARCH_SYNC_MULTILINE_MAX` 64 KiB と `SEARCH_HEAVY_REPEAT` 1000) は製品の振る舞いを変えるので、この記録では変えず、案として残す (同期検索の条件を窓の大きさと繰り返しの上限の積で決める、または同期検索に限って判定の値を 100〜200 程度に下げる、など)。
- BM-109m-heavy の 1 回目の比の揺れ (0.74〜1.46、最大 262 ms) は 1 巡だけの外れで、2 回目は 1.08〜1.11 だった。重い側 (`{0,1001}`。核を 16 KiB から始めて倍にする) も、短い行の 100 MB では軽い側とほぼ同じ速さ (比 1.10) で、判定の値の境で走査の速さは崩れない。
- 次 / 前 (保持に無い位置から、単発のジョブ) は 100 MB でも 1〜2.4 ms で、再開の位置 (1 MiB ごと) から走るので文書の大きさに依らない。5 回の連打は 1 回のジョブにまとまる。
- 上限の無いパターンの全文の連結は、16 MiB の上限の文書で 24〜27 ms。この間 (1 回の `regex` の呼び出し) は取り消せないが、取り消しの遅れの目安 50 ms (03 §12.3.1 の「例外」) の内に収まる。
