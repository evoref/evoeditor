## 所見

- 自動の 26 項目がすべて ○ で、× と - は無かった。
- 結果の「コミット」の欄 (`593de5bbbb9a`) は、取り出したソースを置いた作業用のリポジトリのコミットで、中身は判定コミット `4327f18` の `git archive` と同じ。
- リポジトリのある外付けのドライブ (exFAT) の上 (`/mnt/e`) では、`dist` のアーカイブの内容物の検査が、展開したファイルの時刻を設定できずに止まる (`tar: Cannot utime: Invalid argument`)。製品の問題ではない。ソースを WSL の ext4 に取り出して走らせた。xtask はリポジトリの場所を組み込むので、`CARGO_TARGET_DIR` も別にする (同じ target の xtask を使うと `/mnt/e` を使い続ける)。
