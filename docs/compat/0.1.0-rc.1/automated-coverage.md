# 互換性の手順書のうち、自動テストで確認した行 (v0.1.0-rc.1)

[`../checklist.md`](../checklist.md) の A (起動と終了) と H (異常終了と退避) の行は、実バイナリを ConPTY で起動して画面と終了コードを確かめる
E2E テスト (`bins/evoeditor/tests/e2e.rs`、CI の `e2e` ジョブで毎回実行) で確認している。PO の判断 (2026-10-24) により、これらの行は手動での
再確認を省き、このファイルの対応で代替する。手動で確認するのは B (日本語入力)・C (表示とキー)・D (貼り付けとクリップボードの実操作)・
E〜G の端末での目視・I (受入) と、H1 の Windows Terminal でのタブ閉じの 1 回である。

**限界**: ConPTY は conhost の疑似端末の仕組みで、実際の Windows Terminal・conhost のウィンドウそのものではない。ウィンドウを閉じる操作
(H1) は、コンソールイベント `CTRL_CLOSE_EVENT` を直接送って確かめている。Windows Terminal のタブを実際に閉じたときに同じイベントが届くことは、
この自動テストでは確かめられないので、**H1 の目視を Windows Terminal で 1 回だけ手動で行う** (タブを閉じ、退避ができていることを見る)。
