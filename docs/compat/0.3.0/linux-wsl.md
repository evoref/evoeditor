## 所見

- `cargo xtask dist` は `CARGO_TARGET_DIR` を指定すると、指定先ではなくリポジトリの `target/` から実行ファイルを探して失敗する (分割デバッグ情報の `objcopy` の段)。今回は指定せずに作った。リリースの後に直す (判定の後は記録以外を `develop` に入れない、09 §9.2)。
