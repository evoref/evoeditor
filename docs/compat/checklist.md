# 互換性・手動受入の手順書 (v0.1)

リリースの前に、基準機 (Windows 11) の **Windows Terminal** と **conhost** で、この手順書の項目を実機で確かめる (docs/09 §3.7 / §3.8、05 §9.4、08 §2.2 のリリースゲート (5))。結果は版ごとに `docs/compat/<版>/windows-<端末>.md` (雛形: [`_template/windows-terminal.md`](_template/windows-terminal.md)) に書き、手順 H と I は `docs/compat/<版>/acceptance.md` に書く。タグの前に `develop` にコミットする。

**書かないもの**: 基準機の固有情報 (機種名・型番・OS のビルド番号・ウイルス対策ソフトの製品名・ユーザー名を含むパス)。Windows と端末は **版 (例: Windows 11 24H2 級、Windows Terminal 1.24 系)** までにする (docs/11 §9.7)。

## 準備

1. 配布物の exe で確かめる。`cargo xtask dist` で作った zip を展開した `evoeditor.exe` を使う (開発ビルドではない)。
2. 設定ファイルが無い状態 (`EVE_CONFIG_DIR` を空のフォルダに向ける) と、`config.example.toml` を写した状態の両方で起動できることを、最初に 1 回ずつ確かめる。
3. 端末ごとに新しいウィンドウで始める。確かめる端末: **Windows Terminal** (判定の対象) と **conhost** (機能の確認。描画の品質は best effort)。
4. 日本語入力は **Microsoft IME** と **Google 日本語入力** のそれぞれで確かめる (どちらも入っていなければ、入れてから)。
5. 手順の中で使うファイルは、リポジトリの外の作業フォルダに作る (内蔵 SSD)。個人の文書は使わない。

各項目の結果は **○** (期待どおり)・**△** (動くが気になる点あり。内容を備考に)・**×** (期待どおりでない。内容と再現手順を備考に) のいずれかで書く。× と △ は Issue にし、番号を備考に書く。× が 1 つでもあれば、原因を調べてからゲートを判定する。

## A. 起動と終了

| # | 手順 | 期待 |
|---|---|---|
| A1 | `evoeditor` を引数なしで起動する | 無題の文書の画面が出る。ステータスバーに `無題-1`、ヒントバーが出る |
| A2 | `Ctrl+Q` で終了する | 終了し、端末が元の状態に戻る (代替スクリーンを抜ける・カーソルが出る・色が戻る) |
| A3 | `evoeditor --version` と `evoeditor --help` | 版と使い方が出る。`--version` は配布 zip の版と一致する |
| A4 | 存在しないパスを指定して起動し、保存する | 新規ファイルとして保存できる |
| A5 | 日本語のファイル名 (`日本語.txt`) の UTF-8 のファイルを引数で開く | 本文が崩れずに出る |

## B. 日本語入力 (IME)

編集面・コマンドパレット (`F1`)・入力プロンプト (`Ctrl+G` の行番号など)・検索バー (`Ctrl+F`) の入力欄のそれぞれで確かめる。

| # | 手順 | 期待 |
|---|---|---|
| B1 | IME をオンにして 3 文を入力する (変換・確定) | 変換中の文字が編集位置に出る。確定した文字列が正しく入る |
| B2 | 変換中に `Esc` で取り消す | 変換が取り消され、確定前の文字は入らない |
| B3 | 変換候補のウィンドウの位置 | カーソルの近くに出る (画面の端に飛ばない) |
| B4 | 長い行 (画面幅より長い) の末尾で入力する | 候補の位置がずれない。画面が崩れない |
| B5 | 全角文字・絵文字・半角カナを入れて、矢印キーと Backspace で動かす | カーソルが文字の境界で動く。表示が崩れない |

## C. 表示とキー

| # | 手順 | 期待 |
|---|---|---|
| C1 | ウィンドウの大きさを変える (大きく・小さく・極端に小さく) | 再描画され、崩れない。極端に小さいときは落ちない |
| C2 | `Ctrl+Shift` を含むキー (`Ctrl+Shift+Z` など) と `Ctrl+Z` | 区別されて動く (元に戻す / やり直し) |
| C3 | 端末が横取りするキー (Windows Terminal の `Ctrl+Shift+P` など) を押す | evoeditor は反応しない (端末の動作になる)。evoeditor 側は `F1` / `Ctrl+P` で代替できる |
| C4 | 色の表示 (検索一致・選択・ダイアログ) | 区別できる。conhost でも記号や属性で区別できる |

## D. 貼り付けとクリップボード

| # | 手順 | 期待 |
|---|---|---|
| D1 | インデント付きの 100 行を他のアプリでコピーし、`Ctrl+V` で貼る | 元のインデントのまま入る。`Ctrl+Z` 1 回で消える |
| D2 | D1 を右クリックの貼り付けでも行う | 同じ結果になる |
| D3 | 本文に `0x13` (Ctrl+S) と `ESC[201~` を含むテキスト (`docs/compat/paste-injection.txt` に添付) を貼る | 保存などのコマンドが実行されない。制御文字は文字として入る / 見える形になる |
| D4 | エディタで選択して `Ctrl+C` し、他のアプリに貼る。他のアプリでコピーして、エディタに貼る | 内容が一致する (日本語・サロゲートペア・改行を含む) |
| D5 | 端末の範囲選択でコピーする (v0.1 はマウスを捕捉しない) | 端末の動作でコピーできる |
| D6 | 大きな選択 (数 MB) をコピー・貼り付けする | 固まらず、入力が止まらない |

## E. 検索と置換

| # | 手順 | 期待 |
|---|---|---|
| E1 | `Ctrl+F` で検索し、`Enter` / `Shift+Enter` で次・前へ | 一致が強調され、件数が出る。末尾で折り返す |
| E2 | `Ctrl+R` ですべて置換し、`Ctrl+Z` で戻す | 置換され、1 回の元に戻すで戻る |
| E3 | 日本語の語・大文字小文字を含む語を検索する | 大文字小文字の切り替えが効く。日本語が見つかる |

## F. ファイルの読み書き

| # | 手順 | 期待 |
|---|---|---|
| F1 | 日本語を含む UTF-8 のファイルを開き、1 文字入れて `Ctrl+S`、`Ctrl+Q` | 保存され、中身が期待どおり。改行コードが保たれる |
| F2 | Shift_JIS のファイルを開く (ステータスバーの文字コード表示を見る)。編集して保存する | 文字コードが `Shift_JIS` と出る。元の文字コードで保存される |
| F3 | 読み取り専用のファイルを開く | 読み取り専用と出て、編集は理由つきで拒否される |
| F4 | 開いている間に別のプログラムでそのファイルを書き換え、保存する | 「外部で変更されています」の確認が出て、上書き / 別名で保存 / 中止を選べる |
| F5 | 未保存で `Ctrl+Q` | 保存 / 破棄 / キャンセルの確認が出る。キャンセルで何も変わらない |
| F6 | 存在するファイル名を「名前を付けて保存」に指定する | 上書きの確認が出る |

## G. 巨大ファイル

| # | 手順 | 期待 |
|---|---|---|
| G1 | 100 MB のファイル (`cargo xtask gen-corpus --seed 42` で作る) を開く | 進捗が出る。読込中も入力に応答する。`Esc` で取り消すとすぐ戻る |
| G2 | 512 MiB 超のファイルを開く | 開く前に警告が出る。「読み取り専用で開く / キャンセル」を選べる |
| G3 | 100 MB を開いた状態で `Ctrl+S` | 保存中も入力が止まらない |

## H. 異常終了と退避 (記録は `acceptance.md`)

| # | 手順 | 期待 |
|---|---|---|
| H1 | 編集して未保存のまま、Windows Terminal のタブを閉じる。conhost ではウィンドウを閉じる | 未保存の内容が退避される (`%LOCALAPPDATA%\evoeditor\state\recovery\<日時>-<pid>\`)。`manifest.toml` の `complete = true`。元の改行コード・文字コードが記録されている |
| H2 | H1 の後、evoeditor を起動する | 退避が残っていることと場所が案内される |
| H3 | 大量の出力で端末への書込を詰まらせた状態 (`Get-Content` した巨大ファイルが流れている最中など) でタブを閉じる | 約 5 秒以内に退避が書かれる (`complete = true` または書けた分が残る) |

## I. 受入 (記録は `acceptance.md`)

| # | 手順 | 期待 |
|---|---|---|
| I1 | 説明書なしで「このファイルを開いて 1 行追加して保存して終了する」を行う (画面のヒントだけを見て) | できる (v0.1 は協力者でなく PO 本人でよい。v0.2 から 3 名) |
| I2 | README の「インストール」の手順どおりに、zip を展開して PATH を通し、`evoeditor --version` を実行する (クリーンな Windows 11 でできれば最良。Visual C++ の再頒布パッケージが無い環境) | 手順どおりに進み、起動できる |
| I3 | SmartScreen・Smart App Control の表示 | README の説明どおりか。表示の有無を記録する |

## 記録の書き方

- 項目ごとに ○ / △ / × と備考を書く。
- 端末ごとに、Windows と端末の版、IME の種類 (Microsoft IME / Google 日本語入力) を先頭に書く。
- 結果をまとめた判定 (合格 / 不合格) を末尾に書き、リリースのチェックリストの「互換」「受入」の行から参照する。
