# NFR-601 の簡易テスト (v0.2): 手順と記録

初見の人が、説明書なしで「開く・編集・保存・終了」をできるかを確かめる簡易テストの手順と、その記録です (01 NFR-601、09 §3.8 の L7、OQ-106)。**v0.2 は 3 名の所見を記録して直すだけで、ゲートにしない。** v1.0 は 5 名中 5 名の成功がゲートになる。

記録には **個人を特定できる情報を書かない** (名前・所属・連絡先・画面に写る個人のファイル名。協力者は P1〜P3 と書く、12 §5.6 の PC-1〜PC-7)。

## 1. 準備

| 項目 | 内容 |
|---|---|
| 協力者 | 端末 (コマンドライン) に慣れていない人を 3 名。evoeditor を使ったことがない人。開発に関わっていない人 |
| 版 | テストに使う evoeditor の版を記録する (`evoeditor --version` の出力)。v0.2 のリリース候補か、`develop` のビルド |
| 環境 | Windows 11 の Windows Terminal (既定のプロファイル、既定のフォントと大きさ)。日本語の IME を使える状態 |
| ファイル | 協力者ごとに新しく作った `test.txt` (UTF-8、改行 CRLF、3 行: `りんご` / `みかん` / `ぶどう`)。前の協力者の結果を消してから渡す |
| 起動 | 進行役が端末で `evoeditor test.txt` を起動した状態で席を替わる (起動の手順はテストの対象にしない) |
| 記録の道具 | 時計 (経過時間)、このファイルの「3. 記録」の表。画面の録画はしない (個人の情報が写り得るため) |

## 2. 進め方

1. 協力者に次の **課題** を口頭で伝える。紙に書いて渡してもよい。これ以外の説明はしない。
   > 「このファイルの最後に『ばなな』という行を 1 行足して、保存して、エディタを終了してください。」
2. 進行役は **画面に出ている文字 (ヒントバー・メッセージ・ダイアログ) 以外の助言をしない**。質問には「画面に出ている内容で判断してください」とだけ答える。
3. 協力者には、考えていることを声に出してもらう (思考発話)。進行役は言葉と迷った場所を書き取る。
4. **10 分** で打ち切る。10 分以内に課題が終わらなかった、または協力者が諦めた場合は「失敗」とする。
5. 終わった後に 3 つだけ聞く: (a) いちばん迷ったところ、(b) 画面のどの表示が役に立ったか、(c) 分かりにくかった言葉。
6. ファイルの内容を確かめる (`ばなな` の行があり、ほかの 3 行と改行 CRLF が保たれているか)。

**成功の条件**: 10 分以内に、(1) `ばなな` の行を足し、(2) 保存し (ファイルに反映され)、(3) エディタを終了した。途中で誤った操作をしても、自分で戻せていれば成功とする。
